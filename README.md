## Weekly newsletter

Start at [newsletter/WORKFLOW.md](newsletter/WORKFLOW.md). It contains the agent-independent preparation, data, writing and automatic Wednesday publishing process. AJ has authorized publication and one league-chat link at **08:00 America/New_York**, with provisional preparation at 07:00. The original regular design remains the default; supported holiday editions are selected for the Wednesday on or immediately before their holiday.

Runs currently need the **Office Windows host**, Python 3.12+, Git/GitHub access, internet for public Sleeper/ESPN data, and an authenticated Sleeper browser session as **JeffyWaterton** to post in Rebuilders Anonymous. NFL MCP normally runs at `http://127.0.0.1:9000/mcp/`; it supplements reporting and may have empty caches. No credentials or browser state are stored here. The offline example works without those live services. No named model or subscription is required. See [data and recovery](newsletter/DATA.md) and [publication/delivery](newsletter/PUBLISHING.md).

The scheduler is managed by the parent task on Office, not GitHub Actions. ESPN/wife-league work is separate and remains draft-only.
