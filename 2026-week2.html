Methods

  • Elo: Continued from post-W1 ratings (W1 winners 1016.0 / losers 984.0). Updated only from Week 2 actual results. K=32.
  • Expected score (plain English): For ratings Ra and Rb, expected win chance for A is 1 / (1 + 10^((Rb−Ra)/400)). New rating = old + 32 × (actual result − expected), where actual is 1 for a win and 0 for a loss. Equal pre-match ratings → winner +16.00 / loser −16.00. Favorite (1016) over underdog (984) → favorite +14.53 / underdog −14.53.
  • Power board: Elo descending, then record, then PF. No FantasyCalc / market dollars in ranks or matchup copy.
  • Data: Sleeper via nfl-mcp — get_matchups(week=2), get_rosters, get_league_users, get_transactions (weeks 2–3), get_nfl_state.
  • NFL state note: display_week=2 while week=3 / leg=3; this issue treats Week 2 as the scored leg. Week 3 is not settled.
  • Trades: No type=trade in the W2 window (one waiver only — not covered here).
  • Gaps flagged: hammball empty K slot (player_id=0) counted as 0.0 starter, not a named player; roster settings.fpts are truncated integers — pack PF/PA use full matchup floats.
  • Status: Published revision 2026-09-22. Scores and Elo above are pack-sourced only.
